## 💻 Code Examples

### JavaScript (Frontend)

```javascript
// Create Cherry's profile
const cherry = await PetAPI.create({
    name: "Cherry",
    breed: "Golden Retriever",
    dateOfBirth: "2021-10-18",
    gender: "Female",
    color: "Golden"
});

// Add medication
const medication = await MedicationAPI.create({
    petId: cherry.id,
    name: "LiverCare Syrup",
    dosage: "5ml twice daily",
    quantityRemaining: 30,
    refillDate: "2025-01-15",
    isActive: true
});

// Get all medications
const meds = await MedicationAPI.getByPetId(cherry.id);

// Add growth record
const growth = await GrowthTrackingAPI.create({
    petId: cherry.id,
    trackingDate: "2025-12-04",
    weight: 28.5,
    height: 58.0,
    ageMonths: 38,
    notes: "Healthy weight"
});
```

## 🐛 Troubleshooting

### Backend Won't Start
```bash
# Check Java
java -version  # Should be 17+

# Check Maven
mvn -version   # Should be 3.6+

# Check port
netstat -an | findstr 8080  # Windows
lsof -i :8080               # Linux/Mac
```

### API Not Working
1. Verify backend is running
2. Check browser console for errors
3. Test with curl or Postman
4. Review backend logs

### Database Issues
1. Delete petcare.db and restart
2. Check file permissions
3. Verify SQLite driver loaded
