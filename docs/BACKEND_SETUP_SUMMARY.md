## How to Use

### Step 1: Install Prerequisites
- Java 17 or higher
- Maven 3.6 or higher

### Step 2: Start Backend

**Windows:**
```bash
start-backend.bat
```

**Linux/Mac:**
```bash
chmod +x start-backend.sh
./start-backend.sh
```

**Or manually:**
```bash
cd backend
mvn spring-boot:run
```

### Step 3: Access Application
- Backend API: http://localhost:8080/api
- Frontend: Open index.html in browser

### Step 4: Test API

```bash
# Test if backend is running
curl http://localhost:8080/api/pets

# Create Cherry's profile
curl -X POST http://localhost:8080/api/pets \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Cherry",
    "breed": "Golden Retriever",
    "dateOfBirth": "2021-10-18",
    "gender": "Female",
    "color": "Golden"
  }'
```

## Migration Path

### Current State
- Frontend uses localStorage
- Data stored in browser only
- No persistence across devices

### After Migration
- Frontend uses REST API
- Data stored in SQLite database
- Accessible from any device
- Persistent and backed up

### Migration Steps
1. Start backend server
2. Keep existing localStorage code as fallback
3. Add API calls alongside localStorage
4. Test thoroughly
5. Remove localStorage code
6. Enjoy persistent data!

## Example Usage in Frontend

```javascript
// Load medications when page loads
window.addEventListener('load', async function() {
    try {
        // Get Cherry's medications (assuming Cherry's ID is 1)
        const medications = await MedicationAPI.getByPetId(1);
        
        // Display medications
        medications.forEach(med => {
            displayMedication(med);
        });
    } catch (error) {
        console.error('Failed to load medications:', error);
        // Fallback to localStorage if needed
    }
});

// Save new medication
async function addMedicationTracking() {
    const name = document.getElementById('medName').value;
    const dosage = document.getElementById('medDosage').value;
    const quantity = document.getElementById('medQuantity').value;
    const refillDate = document.getElementById('medRefillDate').value;
    
    if (name && dosage && quantity && refillDate) {
        try {
            const result = await MedicationAPI.create({
                petId: 1,
                name: name,
                dosage: dosage,
                quantityRemaining: parseInt(quantity),
                refillDate: refillDate,
                isActive: true
            });
            
            console.log('Medication saved:', result);
            // Update UI
            displayMedication(result);
        } catch (error) {
            console.error('Failed to save medication:', error);
        }
    }
}
```

## Troubleshooting

### Backend won't start
- Check Java version: `java -version`
- Check Maven: `mvn -version`
- Check port 8080 is free

### API not accessible
- Verify backend is running
- Check console for errors
- Test with curl or Postman

### Database errors
- Delete petcare.db and restart
- Check file permissions
- Verify SQLite driver loaded
