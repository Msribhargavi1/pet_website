# Pet Health Management Backend - Python/FastAPI

## 🚀 Standalone Backend Repository

This is the Python/FastAPI backend for the Pet Health Management System.

## 📦 Repository Setup

This repository contains only the backend code and can be deployed independently.

### Quick Start

```bash
# Clone the repository
git clone <your-repo-url>
cd backend-python

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run the server
uvicorn app.main:app --reload --port 8080
```

### Access Points

- **API**: http://localhost:8080
- **Swagger Docs**: http://localhost:8080/docs
- **ReDoc**: http://localhost:8080/redoc
